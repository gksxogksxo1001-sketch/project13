논문의 결론 중 어떤 결과를 누구를 돕는 기능으로 바꿀지 정의한 ‘앱이 될 한 문장(BRB-C01)’과 ‘사용자가 할 일 3가지(① 16초 임계치 진단 및 12.7초 폴링 방어 청각 타이머, ② 78.3% 중간 옵션 편향을 교정하는 1줄·위험도 요약기, ③ 10분 디버깅 기반 4줄 구조화 프롬프트 및 36건 대조)’를 직접 기획하고 12번 포트폴리오 사이트의 대표작 2 슬롯에 직결했습니다.

              

              

                ③ AI 제안을 따르지 않은 일 (이유 포함)
                
AI는 초기 설계에서 외부 유료 LLM API 키 입력을 요구하는 챗봇 형태와 일반 뽀모도로(25분) 타이머를 제안했으나, 본 과제의 핵심은 “로그인·비밀값 없이 새 시크릿 창에서 즉시 열리고 논문의 실제 실측 수치(16초 임계치, 12.7초 시각적 폴링 91.7%, 78.3% 중간 옵션 편향)가 코드로 작동하는 것”이므로 외부 API 의존성과 무관한 일반 타이머를 전면 배제하고 논문 수식 기반의 무인증 독립 웹앱으로 직접 교정했습니다.
