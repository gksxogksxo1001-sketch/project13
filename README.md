### ① 이 앱은 누구를 어떻게 돕는가 (앱 한 문장)
> **“AI 코딩 에이전트(Antigravity, Copilot 등)와 협업하는 웹 개발자가 16초 이상의 응답 대기 시간 동안 에디터를 힐끔거리며 주의가 분산되거나(12.7초 주기 시각적 폴링 91.7%) 장문의 3지선다 모달에서 2번째 옵션만 편향 선택할 때(78.3%), 이 앱이 논문의 36회 실측 결과([표 2] 구간별 행동 확률)와 3대 제언 규칙을 써서 ① 대기 구간별 맞춤형 UI·콘솔 검수 가이드와 무폴링 청각 타이머 작동, ② 3지선다 장문 옵션의 '1줄 핵심 + 위험도' 요약 변환, ③ 에러 로그 결합 3~5줄 구조화 프롬프트 생성 및 36회 원자료 실시간 비교를 해 줍니다.”**

### ② 사용자가 앱에서 실제로 할 일 세 가지 (BRB-C02)
1. **[할 일 1 / STEP 1] 대기 시간(초) 입력 및 무폴링(Zero-Polling) 청각 타이머 · 검수 체크리스트 실행**:
   - 예상 대기 시간(초)을 입력(또는 원클릭 예시 선택)하면 논문 [표 2]의 3구간 규칙(`0~15초 IDE 주시 80.0%` / `16~30초 화면 검수 54.5%` / `31초+ 화면 검수 66.7%`)에 맞춰 지금 할 F12·375px 반응형 검수 할 일을 처방받고, 완료 알림음 타이머로 `12.7초` 주기의 시각적 폴링(힐끔거림)을 0회로 줄입니다.
2. **[할 일 2 / STEP 2] 에이전트의 3지선다 장문 모달을 ‘1줄 핵심 + 위험도 뱃지’로 요약·비교하기**:
   - 에이전트가 띄운 복잡한 3가지 옵션을 넣거나 예시 시나리오(사례 A/B/C)를 불러오면, 긴 설명 때문에 2번째 중간 옵션만 누르는 편향(`78.3%`)을 경고하고 옵션별 핵심 1줄·위험도·적합도 점수로 요약해 최적 선택지를 추천합니다.
3. **[할 일 3 / STEP 3] 에러 로그를 ‘4줄 구조화 프롬프트’로 변환하고 내 세션을 논문 36회 데이터와 비교하기**:
   - 10분 자체 디버깅 후 확인한 F12 에러 로그와 원하는 UI 흐름을 입력해 에이전트 1회차 성공률을 높이는 4줄 프롬프트를 생성·복사하고, 내 대기 세션을 기록해 논문 공개 데이터(36건) 통계와 실시간 대조 및 CSV 다운로드를 수행합니다.

### ② 사용자가 할 일 세 가지를 어떻게 해 보는가
1. **할 일 1 (`STEP 1`)**: 화면 상단 `[✨ 원클릭 자동 시연]`을 누르거나, STEP 1에 `25`(또는 예시 버튼 `12초` / `25초` / `48초`)를 넣고 `[🔍 논문 규칙으로 행동 진단하기]` 및 `[▶️ 무폴링 타이머 시작]`을 클릭합니다.
2. **할 일 2 (`STEP 2`)**: STEP 2에서 `[사례 A/B/C]` 예시 버튼을 누르거나 옵션 1·2·3 텍스트를 넣고 `[⚡ 1줄 핵심 + 위험도 요약 및 편향 분석 실행]`을 클릭합니다.
3. **할 일 3 (`STEP 3`)**: STEP 3에서 `[✨ 4줄 구조화 프롬프트 생성]`과 `[➕ 내 세션 기록 추가 및 논문 데이터와 비교]`를 클릭합니다.
4. **예외 입력 방어 테스트 (`BRB-C05`)**: 첫 화면의 `🛡️ BRB-C05 잘못된 입력 방어 검증` 바에서 `[빈 값("") 입력]`, `[음수(-45초) 입력]`, `[문자열("abc오류") 입력]`, `[초대형 값(99999초) 입력]` 버튼을 클릭합니다.

### ③ 무엇이 나오면 통과(정상)인가
- **할 일 1 통과**: 우측 카드에 `0~15초(IDE 주시 80.0%)`, `16~30초(화면 검수 54.5%)`, `31초+(화면 검수 66.7%)` 확률 바, `시각적 폴링 감축 횟수(예: 2회 ➔ 0회)` 및 체크리스트 3개가 나타나고 타이머가 카운트다운되면 통과입니다.
- **할 일 2 통과**: 우측에 `78.3% 중간 옵션 편향 경고`와 함께 옵션 1·2·3이 각각 `핵심 1줄 요약 + 위험도 뱃지 + 적합도 점수` 카드로 변환되면 통과입니다.
- **할 일 3 & 예외 방어 통과**: 4줄 디버깅 프롬프트가 출력되고 총 분석 세션 수가 `36건 ➔ 37건`으로 갱신되며, 잘못된 입력 버튼 클릭 시 앱이 멈추지 않고 상단에 노란색 `🛡️ 입력값 자동 방어 및 안전 보정` 배너가 뜨면 통과입니다.

## 💡 5. AI와 나의 판단 세 줄 (BRB-C14)

1. **[① AI에게 맡긴 일]**: 10번 논문의 36회 실측 원자료(CSV)와 [표 2] 확률 분포를 JavaScript 모듈로 구조화하고, Web Audio API 무폴링 타이머, 3지선다 요약 카드 UI, 예외 입력(빈 값·음수·문자열·초대형 수치) 방어 스캐폴딩 및 1초 자동 검증 스크립트(`verify-app.js`)를 작성하는 일을 맡겼습니다.
2. **[② 내가 직접 판단한 일]**: 논문의 결론 중 어떤 결과를 누구를 돕는 기능으로 바꿀지 정의한 ‘앱이 될 한 문장(BRB-C01)’과 ‘사용자가 할 일 3가지(① 16초 임계치 진단 및 12.7초 폴링 방어 청각 타이머, ② 78.3% 중간 옵션 편향을 교정하는 1줄·위험도 요약기, ③ 10분 디버깅 기반 4줄 구조화 프롬프트 및 36건 대조)’를 직접 기획하고, 동료의 익명 한 줄 감상(BRB-C11)과 함께 12번 포트폴리오 사이트의 대표작 2 슬롯에 나란히 연결했습니다.
3. **[③ AI 제안을 따르지 않은 일 (이유 포함)]**: AI는 초기 설계에서 외부 유료 LLM API 키 입력을 요구하는 챗봇 형태와 일반 뽀모도로(25분) 타이머를 제안했으나, 본 과제의 핵심은 **"로그인·비밀값 없이 새 시크릿 창에서 즉시 열리고 논문의 실제 실측 수치(16초 임계치, 12.7초 시각적 폴링 91.7%, 78.3% 중간 옵션 편향)가 코드로 작동하는 것"**이므로 외부 API 의존성과 무관한 일반 타이머를 전면 배제하고 논문 수식 기반의 무인증 독립 웹앱으로 직접 교정했습니다.
